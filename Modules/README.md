# Day 29 — Modules in Python

This lesson explains how Python modules work and why they are essential for clean,
maintainable, and reusable code.

## Topics Covered
- What modules are and why they exist
- Creating user-defined modules
- Different ways to import modules
- Built-in modules (math, random, datetime)
- Using aliases while importing
- Checking module contents with dir()
- __name__ == "__main__" concept
- Real-world utility module examples
