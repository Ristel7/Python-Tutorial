# Mini Data Analysis Project — Sales Performance

This project demonstrates a complete end-to-end data analysis workflow
using Python in a single structured folder.

## Objective
Analyze monthly sales and expenses data to understand trends,
regional performance, and overall profitability.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Workflow
1. Load CSV data
2. Perform data inspection and cleaning
3. Create profit feature
4. Analyze sales and profit metrics
5. Build a dashboard-style visualization
6. Save dashboard as an image

## Files
- sales_data.csv → raw dataset
- project_analysis.py → full analysis code
- dashboard.png → generated visualization

## Key Insights
- Sales show a consistent upward trend
- North region contributes higher total sales
- Profits increase over time but expenses also rise
- Business growth is positive with scope for cost optimization
