**# Day 28 — Error Handling in Python**

This lesson explains how Python handles runtime errors and how to write safe,
robust programs using try, except, else, and finally blocks.

## Topics Covered
- Basic try-except
- Handling invalid input
- Multiple except blocks
- else and finally usage
- Catching multiple exceptions
- Generic exception handling
- Raising custom exceptions
- Creating custom exception classes
- Real-world examples:
  - Login system
  - Safe calculator
