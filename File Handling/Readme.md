# Day 30 — File Handling in Python

This lesson explains how Python interacts with files to read, write, append,
and manage data stored on disk.

## Topics Covered
- Opening and closing files
- Read, write, append modes
- Using with statement (best practice)
- Reading files line by line
- Writing multiple lines
- File pointer (tell & seek)
- Checking file existence
- Deleting files safely
- Handling file-related errors
- Real-world examples:
  - Logging system
  - Simple notes app
