📘 Python Loops (Basic)
This lesson covers the core ideas behind loops in Python.
The examples help you understand when to use a for loop, when to use a while loop, and how break and continue affect the flow.
What’s included:
Looping through lists
Using range()
Getting index and value using enumerate()
Basic while loops
How break stops a loop
How continue skips an iteration
Looping through strings
Looping through dictionaries
