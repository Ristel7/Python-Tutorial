Strings (In-depth)

This lesson explores Python strings in full detail — how to access, modify, and format them effectively.

Topics Covered:

String creation and immutability

Indexing and slicing (positive & negative)

Common string methods (upper(), split(), replace(), etc.)

String iteration, concatenation, and repetition

Membership operators (in, not in)

String formatting (f-string, format(), %)

Multiline strings and alignment

Real-world Uses:

Text cleaning and processing

Data formatting and user messages

Generating dynamic output
