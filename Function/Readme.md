
# Day 25 — Defining Functions in Python

This lesson focuses entirely on defining functions in Python.
It explains how functions are created, how data is passed, and how values are returned.

## Topics Covered
- Basic function definition
- Parameters and arguments
- Return statements
- Default and keyword arguments
- *args and **kwargs
- Docstrings
- Nested functions
- Functions calling other functions
- Functions returning functions
- Real-world eligibility example



🧠 **What You Learned**
| Scope Type           | Meaning                                                     |
| -------------------- | ----------------------------------------------------------- |
| **Local**            | Variables created inside a function                         |
| **Global**           | Variables declared outside functions                        |
| **nonlocal**         | Variables in parent function (used inside nested functions) |
| **global keyword**   | Allows modifying global variables                           |
| **nonlocal keyword** | Allows modifying variables in outer (nested) function       |


# Day 27 — Recursion (Functions Calling Themselves)

Recursion is one of the most important concepts in Python. 
This lesson explains how recursive functions work using base conditions, how they stop, and how the call stack grows and returns.

## Topics Covered
- Basic recursive structure
- Base case vs recursive case
- Factorial using recursion
- Fibonacci recursive formula
- Recursively printing lists
- Reversing a string
- Counting digits
- Tracing the flow of recursion
- Real-world examples:
  - Directory tree scanning
  - Binary search

| Concept                | Explanation                               |
| ---------------------- | ----------------------------------------- |
| **Recursion**          | A function calling itself                 |
| **Base Condition**     | Stops infinite looping                    |
| **Recursive case**     | The part that repeats                     |
| **Stack behavior**     | Output before and after recursive calls   |
| **Practical examples** | Factorial, Fibonacci, sum, string reverse |
| **Real-world uses**    | Searching, directory scanning, tree data  |
